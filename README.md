## 怎样更新文章（三步）

**第一步：写文章**

在 `articles` 文件夹里新建一个文本文件，后缀改成 `.md`。

文件名格式：`序号-标题.md`（例如：`192-春日随想.md`）

文件内容格式（开头三行很重要）：

```
# 文章标题

> 分类 | 日期

正文内容写在这里……
```

分类填：诗、词、散文、对联、杂文、游记、歌词、杂记 其中一个。
日期填：如 `乙巳年八月十五` 或 `2025年10月1日`。

序号接着上一篇往下编（现有最后一篇是 191，新文章从 192 开始）。

文件名不要有空格和特殊符号，保存编码选 UTF-8。

---

**第二步：更新网站数据**

双击文件夹里的 `更新网站.bat`，会自动用浏览器打开更新工具。

1. 点"选择文件夹"，选中 ckn 这个文件夹
2. 点"开始更新"
3. 等几秒钟，看到绿色的 ✅ 就说明成功了

---

**第三步：发布上线（用 GitHub Desktop）**

1. 打开 GitHub Desktop 软件
2. 左侧选择 ckn 仓库
3. 左下角填写说明（随便写几个字，比如"新增文章"）
4. 点"Commit to main"提交
5. 点上方"Push origin"推送
6. 推送完成后，打开 PowerShell（开始菜单搜索 PowerShell）
7. 复制粘贴这行命令并回车：

```
npx wrangler pages deploy F:\github-dx\ckn --project-name sxxz --branch main
```

8. 等十几秒，看到"Deployment complete"就发布成功了

> 第三步的第1-5步用 GitHub Desktop，第6-8步需要命令行。
> 如果不方便用命令行，推送后联系千问老师帮忙部署也可以。

## 文章写法举例

```
# 春日随想

> 散文 | 乙巳年八月十五

今天天气很好，去公园散步。
看到柳树发了新芽，想起小时候……
```

诗和词的写法一样，分类写"诗"或"词"即可。

## 网站功能

- 打开网站先看到封面，点"进入文集"进入目录
- 左侧列表是文章目录，可按分类筛选（诗/词/散文/其它）
- 点击文章标题即可阅读
- 点顶部"全文搜索"可搜全部文章
- 阅读时用鼠标选中字词，自动弹出字典释义
- 右上角月亮图标可切换夜间模式，A+/A- 调字号
- 手机浏览器打开同样可用
