## 怎样更新文章（三步）

**第一步：写文章**

在 `articles` 文件夹里新建一个文本文件，后缀改成 `.md`。

文件名格式：`序号-标题.md`（例如：`192-春日随想.md`）

文件内容格式（三行开头很重要）：

```
# 文章标题

> 分类 | 日期

正文内容写在这里……
```

分类填：诗、词、散文、对联、杂文、游记、歌词、杂记 其中一个。
日期填：如 `乙巳年八月十五` 或 `2025年10月1日`。

**第二步：更新网站数据**

双击 `更新网站.bat`，会自动用浏览器打开更新工具。

1. 点"选择文件夹"，选中网站文件夹（就是 ckn 这个文件夹）
2. 点"开始更新"
3. 等几秒钟，看到绿色的 ✅ 就说明成功了

**第三步：发布上线**

更新后还需通知云端。请道玄（或会操作电脑的人）帮忙：

1. 在 ckn 文件夹的空白处，按住 Shift 键 + 鼠标右键 → 选"在此处打开 PowerShell"
2. 输入：`npx wrangler pages deploy . --project-name sxxz --branch main`
3. 回车，等十几秒，看到"Deployment complete"就发布成功了

## 文章写法举例

```
# 春日随想

> 散文 | 乙巳年八月十五

今天天气很好，去公园散步。
看到柳树发了新芽，想起小时候……
```

诗和词的写法一样，分类写"诗"或"词"即可。

---

## 注意事项

- 文件名不要有空格和特殊符号
- 文件保存编码选 UTF-8
- 序号接着上一篇的数字往下编（现在是 191，新的就从 192 开始）
- 不会用电脑没关系，把写好的文章发给道玄，让他帮忙放进去也行

## 网站功能

- **封面页**：打开网站先看到封面，点"进入文集"进入目录
- **文章目录**：左侧列表，可按分类筛选（诗/词/散文/其它）
- **阅读文章**：点击目录中的文章标题即可阅读
- **全文搜索**：点顶部"全文搜索"，输入关键词搜全部文章
- **划词查字典**：阅读时用鼠标选中字词，自动弹出释义
- **夜间模式**：右上角月亮图标，点击切换
- **字号调节**：右上角 A+ / A- 按钮
- **手机阅读**：手机浏览器打开同样可用
